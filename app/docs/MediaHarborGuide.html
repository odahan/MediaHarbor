Media Harbor User Manual

Media Harbor is a Windows desktop application that downloads videos and audio from YouTube (videos, Shorts, music and playlists). It converts downloads to MP4 (video) or MP3 (audio), can embed artwork and subtitles, and includes file conversion and audio trimming tools.

It is powered by yt-dlp and FFmpeg, both bundled with the application — no separate installation is required.

Media availability depends on YouTube and on your own access rights. Only download content you are allowed to keep. Only YouTube links are supported.

Manuel d'utilisation de Media Harbor

Media Harbor est une application Windows qui télécharge des vidéos et de l'audio depuis YouTube (vidéos, Shorts, musique et playlists). Elle convertit les téléchargements en MP4 (vidéo) ou MP3 (audio), peut intégrer pochettes et sous-titres, et inclut des outils de conversion de fichiers et de découpe audio.

Elle s'appuie sur yt-dlp et FFmpeg, tous deux fournis avec l'application — aucune installation séparée n'est nécessaire.

La disponibilité des médias dépend de YouTube et de vos droits d'accès. Ne téléchargez que du contenu que vous êtes autorisé à conserver. Seuls les liens YouTube sont pris en charge.

Requirements

  • Windows 10 or later (64-bit).
  • .NET 8 Desktop Runtime (required if not already installed).
  • An active internet connection.
  • Optional: a cookies file in Netscape format for age-restricted or members-only videos (see Settings).
Launch the application with MediaHarbor.exe. Your settings and history are stored in %LocalAppData%\MediaHarbor (settings.json, history.json). On first use, Media Harbor imports existing files from the data folder next to the executable.

Quick start

1
Choose folder. Click the folder icon and pick where files will be saved (defaults to your Music folder).
2
Choose format. Select Audio (MP3) or Video (MP4).
3
Choose quality. Pick Best, Normal or Custom (bitrate for MP3, resolution for MP4).
4
Download. Copy a YouTube link, then click Paste URL ⬇ or press Ctrl+V. The download starts automatically.

Downloading media

There are several ways to start a download:

  • Paste button / Ctrl+V: copies links from the clipboard. If the clipboard is empty, a box asks you to paste one or more links (one per line).
  • Search bar: paste a URL directly in the search field and press Enter.
  • Auto detection: when enabled, copied links and videos open in your browser are offered automatically (see Auto detection).

Supported links

  • Standard videos: https://www.youtube.com/watch?v=…
  • Short links: https://youtu.be/…
  • Shorts, YouTube Music and playlists.
Other websites are not supported. If you paste a non-YouTube link, the status line reminds you that only YouTube links are accepted.

Download speed limit

Click the speed button in the download list header to throttle new downloads: 250 KB/s, 500 KB/s, 1 MB/s, 2 MB/s, 4 MB/s or Unlimited. The limit only applies to downloads started after the change.

Télécharger des médias

Plusieurs façons de lancer un téléchargement :

  • Bouton Paste / Ctrl+V : récupère les liens du presse-papiers. Si le presse-papiers est vide, une boîte vous invite à coller un ou plusieurs liens (un par ligne).
  • Barre de recherche : collez une URL directement dans le champ de recherche et appuyez sur Entrée.
  • Détection automatique : une fois activée, les liens copiés et les vidéos ouvertes dans votre navigateur sont proposés automatiquement (voir Détection automatique).

Liens pris en charge

  • Vidéos standard : https://www.youtube.com/watch?v=…
  • Liens courts : https://youtu.be/…
  • Shorts, YouTube Music et playlists.
Les autres sites ne sont pas pris en charge. Si vous collez un lien non-YouTube, la ligne d'état rappelle que seuls les liens YouTube sont acceptés.

Limite de vitesse

Cliquez sur le bouton de vitesse dans l'en-tête de la liste pour limiter les nouveaux téléchargements : 250 Ko/s, 500 Ko/s, 1 Mo/s, 2 Mo/s, 4 Mo/s ou illimité. La limite ne s'applique qu'aux téléchargements lancés après le changement.

Playlists

When you add a link containing list= or /playlist, Media Harbor asks whether you want to select entries before downloading:

  • Choose playlist videos opens a selector. Tick the videos you want and confirm to add them as separate downloads. You can close the selector without adding anything.
  • Download this video only adds the video in the link. This option is available when the link identifies a video.
  • Cancel: the link is ignored.
Enable Number playlist entries in Settings to prefix file names with their position in the playlist (01, 02, …) — useful for albums.

Playlists

Quand vous ajoutez un lien contenant list= ou /playlist, Media Harbor demande si vous souhaitez sélectionner les entrées avant le téléchargement :

  • Choose playlist videos ouvre le sélecteur. Cochez les vidéos voulues et confirmez pour les ajouter séparément à la file. Vous pouvez fermer le sélecteur sans rien ajouter.
  • Download this video only ajoute uniquement la vidéo du lien. Ce choix est proposé si le lien désigne une vidéo.
  • Annuler : le lien est ignoré.
Activez Number playlist entries dans les paramètres pour préfixer les noms de fichiers par leur position dans la playlist (01, 02, …) — pratique pour les albums.

Download list

Each entry also offers these actions (icons on the right):

  • Subtitles: downloads subtitles separately — you are asked for a language code such as en, fr or all; files are converted to .srt.

Up to 8 downloads can run simultaneously (configurable in Settings); the others wait for a free slot.

Menu & tools

Click the ⌄ button next to the title to open the application menu.

History

Lists every completed download with its date. From the history you can replay the file, reveal it in Explorer, copy its link or clear the history.

Convert a file

Converts a local media file (mp3, mp4, wav, m4a, aac, webm, mkv, avi, flv, wmv, mov, ogg) to the currently selected format (MP3 or MP4) and quality. Choose the source file, then the output file.

Trim audio

Extracts part of an audio file to MP3. After choosing the file and the output, enter a start time and a duration, either in seconds (90) or as hh:mm:ss (00:01:30). The selected audio bitrate applies.

Settings

Opens the settings dialog — see the next section.

Help

Displays a built-in summary of the application features.

Auto detection

The Auto detect checkbox (search bar area) watches your clipboard once per second. When you copy a valid YouTube link, a dialog offers to download it.

If Detect media in the active browser is also enabled in Settings, Media Harbor additionally watches the URL open in your browser and offers to download the video you are watching.

Each link is only offered once in a row: copying the same link again does not trigger a new prompt until a different text is copied.

Détection automatique

La case Auto detect (zone de la barre de recherche) surveille votre presse-papiers chaque seconde. Quand vous copiez un lien YouTube valide, une boîte de dialogue propose de le télécharger.

Si Detect media in the active browser est aussi activé dans les paramètres, Media Harbor surveille en plus l'URL ouverte dans votre navigateur et propose de télécharger la vidéo que vous regardez.

Chaque lien n'est proposé qu'une fois d'affilée : copier le même lien à nouveau ne déclenche pas de nouvelle invite tant qu'un texte différent n'a pas été copié.

FAQ & troubleshooting

The status says "Paste a YouTube link…"

Only youtube.com and youtu.be URLs are accepted. Check that the link is complete and starts with https://.

A download fails immediately

The video may be unavailable, private, age-restricted or region-locked. For videos that require sign-in, provide a cookies file in Settings. Also check your internet connection and, if you use one, your proxy settings.

Downloads are stuck in "Waiting for a download slot…"

All parallel slots are busy. Wait for a download to finish or raise Simultaneous downloads in Settings (up to 8).

Conversion seems slow

Increase CPU threads used for conversion in Settings. High resolutions (4K/8K) naturally take longer to download and merge.

Where are my files?

In the folder chosen in step 1 (defaults to Music). Use the folder icon on any completed entry to reveal the file in Explorer. Downloaded files are never deleted by the application.

Can I get subtitles only, without the video?

Yes — use the subtitles action on any list entry and enter a language code (en, fr, all). Subtitles are saved as .srt in the download folder.

FAQ & dépannage

L'état indique « Paste a YouTube link… »

Seules les URL youtube.com et youtu.be sont acceptées. Vérifiez que le lien est complet et commence par https://.

Un téléchargement échoue immédiatement

La vidéo est peut-être indisponible, privée, soumise à restriction d'âge ou bloquée par région. Pour les vidéos nécessitant une connexion, fournissez un fichier de cookies dans les paramètres. Vérifiez aussi votre connexion internet et, le cas échéant, vos paramètres de proxy.

Les téléchargements restent en « Waiting for a download slot… »

Tous les emplacements parallèles sont occupés. Attendez la fin d'un téléchargement ou augmentez Simultaneous downloads dans les paramètres (jusqu'à 8).

La conversion semble lente

Augmentez CPU threads used for conversion dans les paramètres. Les hautes résolutions (4K/8K) prennent naturellement plus de temps à télécharger et assembler.

Où sont mes fichiers ?

Dans le dossier choisi à l'étape 1 (Musique par défaut). Utilisez l'icône dossier sur toute entrée terminée pour afficher le fichier dans l'Explorateur. Les fichiers téléchargés ne sont jamais supprimés par l'application.

Puis-je récupérer uniquement les sous-titres, sans la vidéo ?

Oui — utilisez l'action sous-titres sur n'importe quelle entrée de la liste et saisissez un code langue (en, fr, all). Les sous-titres sont enregistrés en .srt dans le dossier de téléchargement.
